# Shared context across machines

When starting on another machine or continuing earlier work, read `~/AI Brain/AGENTS.md`, then `~/AI Brain/memory/MEMORY.md` and the relevant project note. Read the newest relevant file in `~/AI Brain/handoffs/` before editing project files. Check current files before relying on older notes.

Personal notes that must stay on one machine go to `~/.claude/personal-memory/` (not synced), never to the shared memory folder.
