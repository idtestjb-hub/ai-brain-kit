# Shared instructions for every AI assistant (AI Brain)

> Master copy: `~/AI Brain/AGENTS.md`. The copies in `~/.codex/AGENTS.md`, `~/.gemini/GEMINI.md` and `~/.config/opencode/AGENTS.md` are generated by `~/AI Brain/_tools/connect-clients.ps1`. Edit this file, then run that script again.

## Read at the start of each session

1. **Main instructions:** `~/.claude/CLAUDE.md`. They apply to every assistant, whatever tool you are.
2. **Rules:** `~/.claude/rules/`. Read the files that match the folder you work in.
3. **Memory:** `~/AI Brain/memory/MEMORY.md` is the index; each line points to one note in the same folder. Notes can be stale: check files and paths before relying on them.
4. **Handoffs:** when the user continues earlier work, read the newest matching file in `~/AI Brain/handoffs/`.
5. **Skills:** `~/AI Brain/config/skills/<name>/SKILL.md`. When a task matches a skill, read it and follow it.

## Where things live

| What | Real location | Seen in the vault as |
|---|---|---|
| Main instructions | `~/.claude/CLAUDE.md` | `config/CLAUDE (read-only copy).md` |
| Rules | `~/.claude/rules/` | `config/rules/` |
| Skills | `~/.claude/skills/` | `config/skills/` |
| Memory | `~/.claude/projects/<encoded work folder>/memory/` | `memory/` |
| Handoffs | `~/.claude/handoffs/` | `handoffs/` |

`config/`, `memory/` and `handoffs/` in the vault are junctions. Never delete them recursively: remove a junction with `rmdir` (no `/s`).

## Writing

- **New memory note:** one fact per file in `memory/`, with front matter (`name`, `description`, `type: user | feedback | project | reference`), plus one line in `MEMORY.md`.
- **Handoff:** write `handoffs/<yyyy-mm-dd>-<project>-P<n>.md`: what is done, what runs in the background, open items with `[ ]`, suggested next steps.
- **Never edit the same file on two machines while one is offline.** If a `*.sync-conflict-*` file appears, compare both copies and merge by hand.

## Never

- Put passwords, keys, tokens or personal data in this vault or in the config folder.
- Store project data files here (spreadsheets, exports, documents). This vault holds knowledge, not data.
