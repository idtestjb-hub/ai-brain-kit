# Start here

This vault is the shared brain of your AI assistants. It syncs between your machines with Syncthing over Tailscale.

- `AGENTS.md`: instructions every assistant reads first.
- `knowledge/`: notes you write yourself (how-tos, decisions, references).
- `projects/`: one note per project (goal, links, status).
- `memory/`, `handoffs/`, `config/`: junctions into `~/.claude` (filled by the assistants).
- `_tools/`: the kit's scripts. Run `_tools/check.ps1` any time to see the sync status.

You can open this folder in Obsidian as a local vault (keep Obsidian Sync off) or just edit the files in any editor.
